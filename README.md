# ⚡ ElabXCS

**ElabXCS** is a lightweight Chrome-based automation and content analysis utility designed for Elab environments. It combines browser-level automation, content parsing, and database-driven pattern matching to streamline the retrieval of relevant programming references.

Originally developed as a personal utility, the project has grown into a community-driven initiative, with an expanding database powered by user contributions.

## Features

- **Browser Automation:** Streamlined interaction with supported Elab pages.
- **Content Extraction:** Identifies and processes problem descriptions and related content.
- **Database Matching:** Matches extracted content against an existing solution repository.
- **Community Driven:** Expand the database and improve the tool through contributions.
- **Lightweight:** Simple Chrome extension with minimal setup.

## Installation

1. Clone the repository or download and extract the ZIP.
2. Navigate to `chrome://extensions` in Chrome.
3. Enable **Developer Mode**.
4. Click **Load unpacked**.
5. Select the extracted `ElabXCS` directory.
6. Launch the extension from your Chrome toolbar.
